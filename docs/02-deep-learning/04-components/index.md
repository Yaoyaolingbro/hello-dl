# 04 · 可复用组件

一张图像、一个句子和一张社交关系图，应该用同一种操作处理吗？通常不该。它们分别带有局部空间、先后顺序和邻接关系。网络组件把这些结构假设写进计算：卷积在局部窗口共享参数，循环状态沿时间传递，注意力按内容寻找信息，消息传递沿图的边聚合。

本目录只拆解这些“零件”。每一页都回答五个问题：做了什么运算、张量形状怎样变化、引入什么[归纳偏置](../02-neural-network-foundations/inductive-bias.md)、大致花多少计算与内存、最容易怎样失效。至于一套完整网络堆多少层、按什么顺序连接、接什么任务头，留给下一目录的[模型架构](../05-architectures/index.md)。

## 先统一形状记号

| 数据 | 本目录的常用形状 | 记号含义 |
|---|---|---|
| 图像/特征图 | $[B,C,H,W]$ | batch、通道、高、宽 |
| 序列 | $[B,T,D]$ | batch、序列长度、特征维 |
| 多头注意力 | $[B,h,T,d]$ | batch、头数、位置、每头维度 |
| 图 | 节点 $[N,d_n]$，边 $[M,d_e]$ | 节点数、边数及各自特征维 |

不同库可能把序列轴放在 batch 前面，图也常把多个样本拼成一张不相连的大图。读代码时不要只看层名，先写出每个轴代表什么。

## 六个零件分别解决什么

| 组件 | 核心操作 | 结构假设 | 主要代价或限制 |
|---|---|---|---|
| [卷积](./convolution.md) | 局部窗口内乘加，同一核跨位置复用 | 邻近位置相关，同一模式可在不同位置出现 | 代价随输出面积、核大小和通道数增长 |
| [残差连接](./residual-connections.md) | $\mathbf y=\mathbf x+F(\mathbf x)$ | 让一组变换学习相对恒等映射的修正 | 相加要求形状一致；分支尺度失衡仍会不稳定 |
| [循环状态](./recurrence.md) | 用上一时刻状态和当前输入更新状态 | 时间平移下复用同一更新，过去压进有限状态 | 时间步必须依次执行，长链上的梯度容易衰减或放大 |
| [注意力](./attention.md) | query 与 key 匹配，再对 value 加权求和 | 相关信息可由内容匹配，不限定固定距离 | 全局自注意力的分数矩阵为 $T\times T$ |
| [位置编码](./positional-encoding.md) | 加入或旋转位置相关向量 | 序列顺序本身有意义 | 训练长度、索引约定和外推行为都有边界 |
| [图消息传递](./graph-message-passing.md) | 沿边生成消息，对邻域做置换不变聚合 | 节点关系由图的边给出，编号不应改变语义 | 一层只交换一跳信息；代价通常随边数增长 |

## 组件边界怎么判断

“一次注意力怎样算”“卷积输出多大”属于本目录；“把注意力、前馈层、残差和归一化堆成多少层”属于架构目录。类似地，这里会说明循环状态为何出现长依赖困难，但不会展开 LSTM/GRU 的完整门控布局；会说明图的邻域聚合，但把深层堆叠后的过平滑留给[图神经网络](../05-architectures/graph-neural-networks.md)。

读完本目录，可以按数据结构进入 [CNN 与 ResNet](../05-architectures/cnn-and-resnet.md)、[RNN、LSTM 与 GRU](../05-architectures/rnn-lstm-gru.md)、[Transformer](../05-architectures/transformer.md)或[图神经网络](../05-architectures/graph-neural-networks.md)。这些架构页会组合零件，不再重复本目录的公式。
