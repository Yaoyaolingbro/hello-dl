# 04 · 可复用组件

卷积、残差、循环、注意力和消息传递是多种架构共享的零件。这里讲操作本身，完整模型留到下一部分。

## 你将学到

| 小节 | 核心内容 | 前置依赖 |
|---|---|---|
| [卷积](./convolution.md) | 解释局部连接、参数共享、感受野和输出尺寸。 | 归纳偏置、参数初始化 |
| [残差连接](./residual-connections.md) | 解释恒等路径如何改变优化难度和梯度流。 | 反向传播、归一化 |
| [循环状态](./recurrence.md) | 说明隐藏状态如何编码序列历史，以及长依赖为何困难。 | 感知机与多层感知机、反向传播 |
| [注意力](./attention.md) | 推导缩放点积注意力的形状、掩码与计算复杂度。 | 感知机与多层感知机、归一化 |
| [位置编码](./positional-encoding.md) | 比较正弦、可学习和旋转位置编码传入顺序信息的方式。 | 注意力 |
| [图消息传递](./graph-message-passing.md) | 建立邻域聚合、置换不变性和通用消息传递公式。 | 归纳偏置、感知机与多层感知机 |
