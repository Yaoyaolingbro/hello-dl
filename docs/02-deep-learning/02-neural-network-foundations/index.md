# 02 · 神经网络基础

从线性模型走向神经网络，重点理解多层表示、计算图、损失函数、激活函数和归纳偏置。

## 你将学到

| [计算图与自动微分](./computational-graphs.md) | 用局部计算和依赖关系理解前向计算、局部导数与梯度传播。 | 感知机与多层感知机 |
