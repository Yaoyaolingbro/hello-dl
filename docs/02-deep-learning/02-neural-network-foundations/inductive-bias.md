# 归纳偏置

!!! info "参考资料"
    - Tom M. Mitchell, [The Need for Biases in Learning Generalizations](https://www.cs.utexas.edu/~shivaram/readings/b2hd-Mitchell1980.html), 1980
    - [Relational inductive biases, deep learning, and graph networks](https://arxiv.org/abs/1806.01261) — Battaglia et al., 2018

## 直觉 (Intuition)

有限训练样本往往同时符合许多函数。学习算法必须偏爱其中一些解，才能对没见过的输入作出预测，这种偏好叫归纳偏置 (inductive bias)。偏置不是数据偏见的同义词，也不天然是坏事。卷积假设邻近像素关系重要，图网络假设节点关系重要；假设与任务匹配时，模型会更省数据。

## 为什么无法完全“无偏”

假设训练集中只有两个点：$f(0)=0,f(1)=1$。直线 $f(x)=x$ 能解释它们，高次多项式也能解释，甚至可以构造一个只在这两个点正确、其他位置随意跳变的函数。

数据本身无法决定区间外该怎样预测。选择线性模型，相当于偏爱平滑、简单的延伸；选择决策树，偏爱由轴对齐条件组成的分段规则；选择神经网络和某种训练算法，又引入另一套偏好。

归纳偏置可以来自多个地方：

- 模型结构限制了可表示的函数；
- 损失与正则化规定哪些错误和参数更贵；
- 优化算法在多个可行解中更容易找到某些解；
- 数据增强声明哪些变换不应改变标签。

## 架构怎样写入假设

MLP 对输入维度没有天然的空间理解。把图像像素打乱并固定这种乱序，MLP 仍可训练，只是很难利用局部结构。

卷积把局部连接和平移共享写进网络，因此同一个边缘检测器能在图像各处复用。循环网络复用同一状态更新处理不同时刻。图网络对邻居做置换不变的聚合，因此节点编号改变时结果不会无缘无故变化。

这些假设会在[可复用组件](../04-components/index.md)中逐个展开。这里先注意一个取舍：偏置强，样本效率可能更高，但模型也更难表示违反该假设的规律。

!!! tip "面试重点"
    归纳偏置回答的是“训练数据之外，模型凭什么这样预测”。正则化是归纳偏置的一种来源，架构、优化和数据增强也都是。

## 数据规模会改变选择

数据少时，合适的结构约束能显著缩小搜索范围。数据和算力足够大时，更通用的模型可能从数据中学到原本手工设计的结构，但它仍不是无偏的：参数化方式、优化器和训练目标继续影响最终解。

判断归纳偏置是否合适，不能只看概念是否优雅。要看验证数据是否模拟部署环境，以及替换假设后的消融结果。下一目录进入[模型训练](../03-training/index.md)，看看损失、梯度和优化怎样把这些结构变成具体参数。
