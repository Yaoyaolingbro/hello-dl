# 01 · 机器学习基础

先把机器学习问题说清楚：数据从哪里来、模型学什么、怎样判断它有没有学会。这一部分也是传统机器学习与神经网络之间的桥梁。

## 你将学到

| 小节 | 核心内容 | 前置依赖 |
|---|---|---|
| [学习问题的基本形式](./learning-problem.md) | 说明数据集、假设空间、目标函数、优化与评估之间的关系。 | 无 |
| [线性模型](./linear-models.md) | 从线性回归和逻辑回归建立预测、损失与正则化的基本语言。 | 学习问题的基本形式 |
| [分类与回归](./classification-regression.md) | 区分两类任务的输出、损失、阈值与常见评价方式。 | 线性模型 |
| [决策树与集成学习](./trees-and-ensembles.md) | 解释树模型的划分规则，以及 Bagging、随机森林和 Boosting 的取舍。 | 学习问题的基本形式 |
| [SVM 与核方法](./svm-and-kernels.md) | 用间隔和软间隔理解支持向量机，并建立核技巧的直觉。 | 线性模型、优化基础 |
| [无监督学习](./unsupervised-learning.md) | 介绍聚类、降维与表示学习的基本任务，连接后续深度表示学习。 | 学习问题的基本形式 |
| [泛化与数据](./generalization-and-data.md) | 解释数据划分、泄漏、欠拟合、过拟合和偏差—方差之间的关系。 | 学习问题的基本形式 |

## 与前后章节的关系

这一目录接住 Part 1 的数学工具，并为神经网络的任务定义、损失和泛化建立共同语言。

学完后，继续回到 [Part 2 导读](../index.md) 查看下一阶段。
