# 分类与回归

!!! info "参考资料"
    - [Classification](https://developers.google.com/machine-learning/crash-course/classification) — Google ML Crash Course
    - [Model selection and evaluation](https://scikit-learn.org/stable/model_selection.html) — scikit-learn User Guide

## 直觉 (Intuition)

分类回答“属于哪一类”，回归回答“数值是多少”。两者都能输出一个数字，所以不能靠输出形状判断任务。真正的区别在标签语义、允许的错误以及预测结果怎样进入后续决策。任务定义一旦错了，损失和指标也会跟着错。

## 先看标签，再选模型头

回归标签通常是连续量，例如温度、深度或配送时间。模型输出 $\hat y\in\mathbb R$，误差大小本身有意义。

分类标签来自有限集合。二分类可写成 $y\in\{0,1\}$，多分类可写成 $y\in\{1,\ldots,K\}$。模型往往先输出分数或概率，再经过决策规则得到类别。

| 问题 | 模型输出 | 常见训练目标 | 决策时还要考虑 |
|---|---|---|---|
| 回归 | 连续值或分布参数 | MSE、MAE、负对数似然 | 误差单位、异常值代价 |
| 二分类 | 正类概率或一个 logit | 二元交叉熵、hinge loss | 阈值、误报与漏报 |
| 多分类 | $K$ 个 logits | 多类交叉熵 | Top-1、Top-k、类别代价 |

损失函数会在下一目录单独推导，这里只抓住任务和输出的对应关系。

## 概率不等于类别

设二分类模型输出正类概率 $p$。类别预测还需要阈值 $t$：

$$
\hat y=\mathbb I[p\ge t],
$$

其中 $\mathbb I[\cdot]$ 是指示函数。$t=0.5$ 只是常见默认值，不是数学定律。

垃圾邮件过滤若把正常邮件误删，代价可能很高，于是阈值会设得更高；疾病筛查更怕漏诊，阈值可能降低。模型概率没变，业务决策可以变。完整的 Precision、Recall 和阈值选择放在[指标与决策阈值](../06-evaluation-debugging/metrics-and-thresholds.md)。

!!! warning "常见误区"
    “准确率最高的阈值”不一定是部署阈值。阈值应由误报、漏报和后续人工处理的代价决定，而且只能在验证集上选择。

## 回归不总是预测均值

用平方误差训练时，理论上的最优预测是条件均值 $\mathbb E[y\mid\mathbf x]$；用绝对误差时，对应条件中位数。换损失函数等于改变“什么样的答案最好”。

有些任务表面上输出数值，实际更适合分类。例如年龄被粗略分成儿童、成人和老人时，标签是类别；反过来，评分虽然只有 1 到 5，也可能需要按有序回归处理。不要只看数据类型，要看数值间距是否有意义。

## 多标签和排序不必硬塞进多分类

多分类通常假设一个样本只属于一个类别。图片可以同时含有“汽车”“夜晚”“下雨”，这是多标签问题，每个标签都要独立判断。搜索结果需要比较先后次序，属于排序问题。它们可以共享特征提取器，但目标函数和评估方式不同。

!!! tip "面试重点"
    回答“分类和回归有什么区别”时，不要停在离散与连续。继续说明输出解释、损失、决策规则和指标，这才是模型落地时真正不同的地方。
