# 决策树与集成学习

!!! info "参考资料"
    - [Decision Trees](https://scikit-learn.org/stable/modules/tree.html) 与 [Ensembles](https://scikit-learn.org/stable/modules/ensemble.html) — scikit-learn User Guide
    - [Random Forests](https://doi.org/10.1023/A:1010933404324) — Leo Breiman, *Machine Learning* 45, 2001
    - [XGBoost: A Scalable Tree Boosting System](https://arxiv.org/abs/1603.02754) — Chen、Guestrin, KDD 2016

## 直觉 (Intuition)

决策树把预测拆成一串条件判断。它不要求特征和目标之间是线性关系，也能自然表示“只有两个条件同时满足才危险”这类交互。单棵树很容易跟着训练数据摇摆，集成学习便让多棵树合作。随机森林让树之间尽量不同再平均，Boosting 则让后一棵树专门修正前面的错误。

## 一次分裂在做什么

树在每个节点选择一个特征和阈值，把样本分到左右子节点。分类树希望分裂后的类别更纯。

设节点中第 $k$ 类样本比例为 $p_k$。常用的 Gini 不纯度为

$$
G=1-\sum_{k=1}^{K}p_k^2.
$$

如果节点全是同一类，$G=0$；类别越混杂，$G$ 越大。候选分裂会比较加权后的子节点不纯度：

$$
G_{\mathrm{split}}
=\frac{n_L}{n}G_L+\frac{n_R}{n}G_R,
$$

其中 $n_L,n_R$ 是左右节点样本数。算法选择让 $G_{\mathrm{split}}$ 最小的分裂。使用熵时思路相同，只是把不纯度换成 $-\sum_k p_k\log p_k$。

回归树通常最小化子节点内的平方误差，叶节点输出训练样本目标的均值。

## 单棵树为什么不稳定

树的每次分裂都会改变后续可选路径。训练数据稍有变化，靠近阈值的样本可能跑到另一边，整棵树的下半部分都可能重长。深树能把训练集切得很细，偏差低，但方差高。

限制深度、叶节点最小样本数或剪枝可以缓解过拟合。更常见的办法是集成多棵树。

## Bagging 与随机森林

Bagging 对训练集做多次有放回抽样，每份样本训练一棵树，最后投票或取平均。若不同树的误差不完全相关，平均会抵消一部分波动。

随机森林在 Bagging 之外又加入特征随机性：每个节点只从随机选出的部分特征中寻找分裂。单棵树可能稍弱，但树与树更不相似，平均后的方差通常更低。

!!! tip "面试重点"
    随机森林的两层随机性是 bootstrap 样本和节点级特征子集。只说“训练很多树再投票”还没有解释它为什么比普通 Bagging 更去相关。

## Boosting 是逐步修错

Boosting 不并行训练彼此独立的树，而是构造加法模型：

$$
F_M(\mathbf x)=\sum_{m=1}^{M}\eta h_m(\mathbf x),
$$

$h_m$ 是第 $m$ 棵弱树，$\eta$ 是学习率。梯度提升在每一步拟合当前损失对预测的负梯度。平方误差下，这个量就是残差，所以常被口语化地说成“后一棵树拟合前面的残差”。对其他损失，准确说法应是拟合负梯度。

XGBoost 在梯度提升树的目标和工程实现上加入正则化、二阶近似、稀疏处理与系统优化。它不是一种与 Boosting 无关的新树。

| 方法 | 树之间的关系 | 主要作用 | 常见风险 |
|---|---|---|---|
| 单棵树 | 无 | 可解释的非线性规则 | 方差高 |
| 随机森林 | 并行、去相关后平均 | 降低方差 | 模型较大 |
| 梯度提升树 | 串行修正 | 降低偏差、拟合复杂关系 | 参数不当时过拟合 |

## 什么时候树模型很强

在表格数据上，树能直接处理阈值、缺失模式和高阶特征交互，往往是必须建立的基线。图像、语音和文本的原始输入具有空间或序列结构，树不擅长自动学习这种表示，神经网络通常更合适。

选择模型时不要背“表格用树、图像用网络”的口号。样本量、特征质量、延迟、解释要求和已有表示都会改变答案。[泛化与数据](./generalization-and-data.md)会继续讨论如何用验证结果判断这些选择。
