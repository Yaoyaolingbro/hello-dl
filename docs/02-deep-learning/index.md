# Part 2 · 深度学习基础

Part 2 讨论的不是一串模型名称，而是训练模型所需的完整闭环：怎样定义问题，怎样让参数从数据中学习，怎样组合网络结构，以及怎样判断结果是否可信。

## 阅读路线

    机器学习基础 → 神经网络基础 → 模型训练 → 可复用组件
    → 模型架构 → 评估与排错 → 面试复习

初学者按编号顺序阅读。已有基础、准备面试时，可以先复习神经网络基础和模型训练，再进入架构、排错与面试复习。

## 内容角色

- `Core`：主线必读，后续章节默认已经掌握；
- `Interview`：面试中需要准确解释或现场推导；
- `Research`：连接论文阅读、实验设计或研究方向。

## 七个阶段

| 阶段 | 解决的问题 |
|---|---|
| [01 · 机器学习基础](./01-machine-learning-basics/index.md) | 先把机器学习问题说清楚：数据从哪里来、模型学什么、怎样判断它有没有学会。这一部分也是传统机器学习与神经网络之间的桥梁。 |
| [02 · 神经网络基础](./02-neural-network-foundations/index.md) | 从线性模型走向神经网络，重点理解多层表示、计算图、损失函数、激活函数和归纳偏置。 |
| [03 · 模型训练](./03-training/index.md) | 这一部分把损失变成可执行的参数更新，并解释训练循环中最容易出问题的环节。 |
| [04 · 可复用组件](./04-components/index.md) | 卷积、残差、循环、注意力和消息传递是多种架构共享的零件。这里讲操作本身，完整模型留到下一部分。 |
| [05 · 模型架构](./05-architectures/index.md) | 把前面的组件组合成完整模型，关注结构、数据流、训练特点和适用边界，而不是重复组件公式。 |
| [06 · 评估与排错](./06-evaluation-debugging/index.md) | 训练出一个模型不等于解决了问题。这里讨论指标选择、训练故障、数据漂移、效率和实验可信度。 |
| [07 · 面试复习](./07-interview-review/index.md) | 这里不再重讲整章内容，而是把高频问题映射回唯一的主线章节，训练回答结构和技术取舍。 |

## 前置知识

默认读者学过大学微积分、线性代数和基础概率。遇到矩阵求导、概率分布或优化细节时，正文会链接 Part 1 的对应章节，不在 Part 2 重复展开。
