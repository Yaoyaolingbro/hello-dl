    首页视觉升级与当前章节发布设计¶

    目标与范围¶

    在保留 MkDocs Material 的前提下，重做首页并发布当前已经完成的 Part 2 章节。首页以“亲切、愿意开始学”为主气质，以“前沿、研究视野开阔”为辅；正文框架、搜索、公式和现有教学动画继续沿用。

    本次发布包含：首页、主题配色、现有 Part 2 第 01—04 单元及其教学演示。不把尚未完成的第 05—07 单元包装成已完成内容。

    技术选择¶

    继续使用 MkDocs Material，不迁移到 Vue 或 VitePress。

    • MkDocs 负责 Markdown 教材、目录、全文搜索、公式和静态发布。
    • HTML、CSS、SVG、Canvas 与少量原生 JavaScript 负责首页与正文交互。
    • 交互模块保持独立、轻量，并支持键盘操作和“减少动态效果”。
    • 只有将来出现大量复杂、共享状态的实验工具时，才重新评估局部 Vue 或独立实验子站。

    首页结构¶

    首屏¶

    首屏采用严格的双列网格，避免文字与插画互相侵占：

    • 左侧是短标签、主标题、说明和两个入口按钮；
    • 右侧是固定比例的原创教学插画，置于独立画框中；
    • 标题设置明确的最大宽度，不进入插画区域；
    • 窄屏改为上下排列，插画在文字之后；
    • 图片无法加载时，文字和导航仍完整可用。

    插画不包含文字、公式或品牌标志。画面使用整齐的网格、层叠卡片、数据节点与流动路径表达“从基础走向前沿”，不再使用松散的手绘闭合线和随意漂浮的圆点。

    学习入口¶

    首屏下方提供三个入口：

    1. 主线教材：按章节建立完整知识脉络；
    2. 面试拆解：高频问题、必要推导与训练排错；
    3. 科研速览：领域地图、术语和论文阅读入口。

    随后用四张等高卡片呈现 Part 1—4。桌面端四列，平板两列，手机单列。每张卡片包含定位、适合读者和明确入口，不只显示名称。

    主题配色¶

    全站基色统一为暖白、深靛蓝与青绿色：

    • 暖白用于阅读背景，减轻长文阅读的冷硬感；
    • 深靛蓝用于主按钮、链接和主线教材标签；
    • 青绿色用于科研内容与插画中的前沿感；
    • 柔和橙色只用于面试重点，不与主色争夺层级。

    通过 Material 的自定义颜色变量同时定义亮色与深色方案。正文提示框、表格、按钮、标签和首页卡片共享同一组设计变量，避免局部各自配色。

    动画原则¶

    • 首页只保留低幅度、低频率的层级漂移或路径流动；
    • 正文动画用于解释卷积窗口、计算图等过程，可暂停、重播和逐步播放；
    • prefers-reduced-motion 下自动静止；
    • 不使用 Mermaid；结构图优先使用语义化 HTML 与 SVG。

    内容与质量检查¶

    发布前执行：

    • Part 2 元数据、内部链接和章节状态检查；
    • Python 与 JavaScript 测试；
    • MkDocs 严格构建；
    • 桌面、手机、亮色、深色和减少动态效果的浏览器检查；
    • 首页标题与插画无重叠，四张 Part 卡片等高对齐；
    • 线上首页、导航、公式、图片和教学动画抽查。

    合并与发布¶

    1. 在 rewrite/part2-mainline 完成首页和当前章节收尾；
    2. 将站点地址改为 https://yaoyaolingbro.github.io/hello-dl/；
    3. 部署检查允许“已完成章节 + 明确标注的计划章节”共存，不要求 Part 2 第 05—07 单元提前完成；
    4. 验证通过后将重写分支合并到 main；
    5. 推送 main，由 GitHub Actions 发布到 gh-pages；
    6. 等待发布完成并对线上地址做一次冒烟检查。

    不在本次范围内¶

    • 不整体迁移到 Vue/VitePress；
    • 不在本次发布中编写 Part 2 第 05—07 单元；
    • 不用装饰性动画取代教学内容；
    • 不把未完成章节标记为完成。
